# Autolith 0.33.7

Autolith 0.33.7 finds GNU tar on BSD factory images and gives Linux packaging more time.

- Search `/usr/local/bin`, `/usr/pkg/bin`, and other prefix directories for `gtar` or `gnutar`.
- Install GNU tar from the packaging script when it is absent.
- Raise the Linux GitHub release job timeout to 75 minutes.
