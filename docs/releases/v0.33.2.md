# Autolith 0.33.2

Autolith 0.33.2 fixes GitHub Actions packaging for FreeBSD, NetBSD, and OpenBSD.

- Build the pinned BSD release SBCL with threads so Quicklisp systems that require `:sb-thread` can load.
- Skip NetBSD `mozilla-rootcerts install` when CA certificates are already present.
- Keep OpenBSD CI cores on a wxallowed filesystem instead of `/root`.
