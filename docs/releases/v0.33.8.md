# Autolith 0.33.8

Autolith 0.33.8 installs the default OpenBSD GNU tar flavor so the factory can publish OpenBSD archives.

- OpenBSD packaging installs `gtar--` instead of the ambiguous `gtar` stem.
- The packaging script falls back to `gtar-1.35p1` and fails immediately when GNU tar is still missing.
