# Autolith 0.21.1

Autolith 0.21.1 fixes native Responses compaction compatibility with current
Codex subscription responses.

## Native compaction

- Native compaction requests now carry the same ordinary durable history as
  current Codex, without a synthetic trailing trigger item.
- Autolith accepts the current `compaction` and encrypted
  `context_compaction` checkpoint variants, as well as the legacy
  `compaction_summary` form, and canonicalizes persisted records.
- A valid compaction response without an opaque same-family checkpoint now
  uses the portable summary handoff instead of aborting the conversation.
- Trace-enabled compaction requests preserve the normal reasoning-summary
  setting.
