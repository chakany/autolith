# Autolith 0.48.0

Autolith 0.48.0 adds portable user-data archives and conversation-based localgroup identities.

- Export all portable user data or one workspace with `autolith data export FILE --all` or `autolith data export FILE --workspace DIRECTORY`. Use `(data.export "FILE" :all)` or `(data.export "FILE" :workspace "DIRECTORY")` in a session.
- Import with `autolith data import FILE` or `(data.import "FILE")`. The workspace option relocates a single-workspace archive, including sessions, memories, agendas, plans, papercuts, and associated assets. Imports preserve stable identifiers, reject conflicts before publication, and roll back failed writes.
- Localgroup session IDs match the active conversation ID. Resuming a conversation restores the same localgroup identity; switching conversations updates discovery without replacing the attached terminal connection.
- Verify installer checksums against the exact selected release archive and reject missing, ambiguous, or mismatched checksum records.
- Share update-command and argument handling across source, Nix, and packaged launchers.
- Harden conversation compaction, recovery, process handoff, provider retries, MCP shutdown, and bounded child-task execution and artifact retention.
- Run FiveAM cases in isolated SBCL workers with suite and case selection, CPU-based concurrency, deadlines, timings, and reliable temporary-directory cleanup.
