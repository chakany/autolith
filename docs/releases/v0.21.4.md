# Autolith 0.21.4

Autolith 0.21.4 is a reliability hotfix for provider failures, terminal input,
and automatic crash recovery.

## Safer crash recovery

- Automatic recovery restores the crashed conversation without reopening the
  resume picker.
- Recovery runs one bounded diagnosis turn before repair. It exposes only an
  exact native read-only tool allowlist, confines filesystem inspection to the
  workspace and tracked source, and excludes shell, MCP, hosted, and mutation
  tools.
- The diagnosis explains the likely cause and asks before changing the active
  image.

## Provider and tool reliability

- Temporary HTTP 507 provider failures now receive bounded retries.
- Provider requests are encoded directly as UTF-8 octets, avoiding wide-string
  request failures for non-ASCII input.
- Provider response streams now have explicit ownership and cleanup, preserving
  the original transport error when cleanup also fails.
- Shell output capture is bounded and reports truncation instead of consuming
  unbounded memory.

## Terminal input

- Live composer input now wraps whole words correctly across terminal repaint,
  including wide prompts, styled text, cursor mapping, and sanitized external
  editor content.
