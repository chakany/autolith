# Autolith 0.20.2

Autolith 0.20.2 fixes release-builder cache isolation and stale tool-registry
checks after plan tools landed.

## Release builder

- Each container build clears the shared `/source` ASDF fasl tree so successive
  tags cannot poison each other's checks.

## Tests

- Tool registry expectations include the plan namespace (50 tools, nine
  namespaces) and the immutable-mode count.
- Runtime replacement tests match the quiesce-then-resume model used by
  workspace and conversation switches.
