# Autolith 0.35.0

Autolith 0.35.0 expands revision-gated resources to papercuts and hardens terminal, conversation, process, and provider transitions.

- `papercut:current` lists active reports and creates guarded reports, while `papercut:id/<identifier>` reads or closes one exact report.
- Conversation switches rebuild editable input history from durable user messages, commands, and Lisp without erasing a concurrent draft or cursor position.
- Completion dismissal and active-turn cancellation now cooperate with history traversal, with immediate interruption feedback.
- Deferred inputs are scoped to their conversation, their notices are colorized, and non-error conditions no longer terminate the active image.
- Identifier generation uses native UUID sources across Linux, Darwin, FreeBSD, NetBSD, and OpenBSD, with a portable fallback.
- Git-backed test fixtures explicitly disable inherited commit signing.
- Shell cancellation now retains ownership of a launched process before interruption, closing a race that could leave an untracked child running.
- Provider connection and TLS errors include bounded, credential-redacted underlying diagnostics.
