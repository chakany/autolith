# Autolith 0.44.0

Autolith 0.44.0 adds direct Gemini subscription access and improves terminal command handling, attachment rendering, and release portability.

- Adds Google installed-application OAuth with PKCE and a direct Gemini Code Assist provider supporting account setup, streaming text and thinking, tools, usage accounting, and Gemini model selection.
- Runs prose entered through command-hosted turns in the selected model context and waits for asynchronous attachment dimensions before rendering completed input.
- Preserves double-underscore MCP namespaces and tool names through provider wire encoding.
- Removes Osicat from the packaged dependency closure, replacing its POSIX usage with SB-POSIX so glibc, musl, macOS, and BSD release builds share the supported SBCL interface.
