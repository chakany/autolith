# Autolith 0.46.0

Autolith 0.46.0 adds generic unattended child-agent jobs and makes automatic command authorization fully autonomous and fail closed.

- Adds `run-job`, a non-interactive single-job boundary with bounded data-only S-expression input, native structured-output contracts, role discovery, timeouts, trace and usage reporting, and atomically installed result artifacts.
- Reuses existing provider, MCP, task, tool, spawn, and caller-defined role machinery without adding domain-specific runtime code.
- Validates job envelopes and output contracts before provider work, preserves tagged JSON values exactly, and records categorized terminal failures.
- Makes automatic command authorization consider the current user instructions and return only sandboxed, full-access, or denied outcomes.
- Keeps headless jobs fail closed by denying approval-gated tools and commands instead of opening an interactive picker or honoring approvals from earlier sessions.
