# Autolith 0.33.0

Autolith 0.33.0 ships multi-OS binary releases from GitHub Actions and adds org-templater as a first-party Lisp dependency.

- Build Linux x86-64, macOS arm64, FreeBSD x86-64, NetBSD x86-64, and OpenBSD x86-64 archives in GitHub Actions.
- Mirror those GitHub assets onto the host release service, publish when the Linux archive is ready, and merge later platform files without changing published ones.
- Serve every published platform archive from the download host; latest still requires the Linux archive.
- Pin org-templater for templated Org rendering.
