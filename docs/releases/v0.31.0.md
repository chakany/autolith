# Autolith 0.31.0

Autolith 0.31.0 improves streamed terminal output, resource publication, and runtime coordination while adopting SBCL 2.6.6 and consolidating reusable infrastructure in maintained Lambda Symbolics libraries.

- Preserve every wrapped streamed-output row during live assistant updates, including nested styled tails.
- Publish and verify exact revision-gated resource edits reliably, including extensionless targets, with safe temporary-file cleanup on postcondition failure.
- Improve terminal compatibility through Clinedi's enhanced key decoding, semantic prompt markers, and bracketed-paste lifecycle while preserving physical EOF and multiline paste behavior.
- Use maintained Colordiff and Parenchek libraries for colored change rendering and language-aware Common Lisp, Scheme, and Clojure delimiter checking.
- Use sexp-config's guarded reader boundaries for native configuration, Skills, MCP, and child-agent definitions.
- Delegate worker-name validation, live-thread preflight, and atomic pool-policy refresh to sbcl-workers, sbcl-generations, and cl-jobpond, including fixes for default-runtime admission and lazy-pool refresh races.
- Synchronize all direct Lambda Symbolics dependency refs across Qlot locks and Nix packaging, including corrected cl-colorist, mcparen, sexp-store, and ColorLisp pins.
- Raise the bundled Linux runtime and the default minimum supported SBCL from 2.6.4 to 2.6.6, with matching source identities and Linux/macOS Nix packaging.
