# Autolith 0.19.0

Autolith 0.19.0 improves terminal responsiveness, control of active turns, and
portable Nix development while adding launch-time command authorization.

## Session control and terminal presentation

- Added `--permissions ask|sandbox|full` to select the initial command
  authorization mode for a new or resumed session without changing persistent
  approvals.
- Added Ctrl-C and Escape cancellation for active turns, including durable
  interrupted tool outcomes.
- Wrapped styled live content at word boundaries in terminal previews and
  stream tails.

## Nix and macOS support

- Added macOS arm64 Nix builds and native ColorLisp shared-library handling.
- Reworked the flake around flake-parts for supported Linux x86-64 and macOS
  arm64 development targets.
