# Autolith 0.50.1

## Fullscreen terminal

Start with `autolith --fullscreen`. Scroll through the conversation with the
mouse wheel, PageUp/PageDown, or Ctrl-Home/Ctrl-End. The input box stays at the
bottom. Hold Shift while dragging to select text. In this mode, scroll through
Autolith's history rather than the terminal's scrollback.

## Run Lisp without blocking the prompt

Type `?` followed by a space and a Lisp form, for example
`? (progn (sleep 10) (values :finished 42))`.

The form runs in the active image while you keep using the prompt. Printed
output, errors, and all return values are recorded in the session where you
submitted it. Multiline forms work too. Autolith receives the result when it
can process it; submitting a form does not start a model turn.

## Model catalog

Run `autolith models` to print every known model ID, sorted and one per line.
Pipe it directly to `grep`.

## Windows

- Detach sessions and reconnect through the localgroup client.
- Save exact live-heap checkpoints through a supervised save and restart.
  Checkpointing restarts the active process; the launcher probes the saved image
  before selecting it and reopening the session.
- Wait for background worker restarts before checking their results.
- Check which Lisp system loaded instead of comparing printed paths.

## POSIX command execution

- Bootstrap builds the process-group helper on macOS, FreeBSD, NetBSD, and OpenBSD, so full-access commands work when the workspace sandbox is unavailable.

## Agent fixes

- Child agents can inspect, await, and cancel their background jobs.
- When an RLM budget runs out, retain completed map results and bounded partial
  output. Resume a root run with its existing context and Lisp environment.

Update with `(update)`.
