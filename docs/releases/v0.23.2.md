# Autolith 0.23.2

Autolith 0.23.2 adds authenticated local multi-session control and fixes multiline terminal paste.

- Add `autolith localgroup status`, `tell`, `attach`, `detach`, `pause`, and
  `kill` for private authenticated control of local Autolith sessions.
- Report strict idle state only while waiting for input with no queued or active
  primary work, cancellation, pause, handoff, or live child jobs.
- Support bounded read-only observation, controlling attachment, and live
  take-over with ordered terminal replay and output.
- Preserve session identity, capability, conversation ownership, permissions,
  and composer draft across supervised foreground detach and take-over handoffs.
- Bound and authenticate the length-prefixed loopback protocol, endpoint
  discovery records, response waits, attachment queues, and replay history.
- Preserve unbracketed Ctrl-Shift-V multiline paste as one paste event instead
  of submitting embedded newlines.
