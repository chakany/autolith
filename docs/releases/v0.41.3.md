# Autolith 0.41.3

Autolith 0.41.3 repairs detached-session terminal handoff and shutdown.

- Draws the initial prompt as soon as a controlling terminal attaches.
- Makes idle Ctrl-C shutdown interrupt blocked attachment I/O and exit without another keypress.
- Bounds localgroup server and client cleanup so orphaned processes cannot retain conversation leases indefinitely.
