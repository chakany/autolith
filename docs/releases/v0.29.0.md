# Autolith 0.29.0

Autolith 0.29.0 makes the terminal and operation surface Lisp-first while preserving familiar commands and durable workflow context.

- Evaluate explicit parenthesized input as Common Lisp and expose registered tools, commands, and resources through canonical callable forms.
- Show canonical Lisp forms in startup tips and provider transcripts, with syntax-highlighted drafts and semantic terminal prompt markers.
- Make built-in commands callable from Lisp, advertise their lambda lists, and interactively recover missing arguments.
- Add a styled restart debugger for recoverable local operation failures, and permit safe local operations while a provider turn is active.
- Add `lisp.paren-check` for bounded delimiter analysis across Common Lisp, Scheme, and Clojure source.
- Refine live activity and provider call presentation, including line numbers for added source and change lines.
- Keep Shift-Tab cycling recalled follow-ups unless a command completion selection is already active.
- Persist a bounded FIFO of recent user-initiated operations and outcomes in request-local context without bloating conversation history.
- Document Lisp-first workflows, operation discovery, and continuity across restarts.
