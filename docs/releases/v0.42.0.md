# Autolith 0.42.0

Autolith 0.42.0 adds read-only conversation replay and strengthens live mutation, recovery, authentication, and macOS builds.

- Adds `autolith replay ID` with record stepping and turn, sequence, date, and time navigation without resuming or locking the conversation.
- Makes durable self-modification checks structural, preserves reloadable special-variable semantics, runs input-vault controls promptly, and reports failed clean replay probe output.
- Configures the Darwin SDK library path while building FFF dependencies.
- Preserves terminal file descriptors during OpenCode API-key authentication so hidden input works through detached terminal paths.
