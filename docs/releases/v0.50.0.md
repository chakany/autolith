# Autolith 0.50.0

Autolith 0.50.0 adds native language-server tools, Windows support, an optional fullscreen console, and pristine source recovery.

## Language servers

- Configure trusted language servers in your user `lsp.sexp` and use `lsp.status`, `lsp.query`, `lsp.diagnostics`, and `lsp.restart`. LSP tools are registered only when servers are configured.
- Retain push and pull diagnostics independently, with deduplication and source freshness. Automatic diagnostics after file edits share a short deadline, including server startup and cleanup.

## Terminal and tasks

- Start with `--fullscreen` for an alternate-screen console with a scrollable transcript and pinned composer. Configure the startup boot screen separately.
- Evaluate Lisp asynchronously with `?` followed by whitespace and a form. Edit recently submitted input through the input vault.
- Send messages between running parent and child tasks. Steering after Escape and Ctrl-C follows FIFO order, including older in-flight messages.
- Use `(compact-tool)` for tool compaction separately from conversation `(compact)`. Configure prompt-cache miss notices with `(cache-misses)`.

## Recursive inference and live state

- Run RLM tools as inspectable asynchronous jobs, reuse a root environment across completions over the same context, and inspect stored objects and traces through `context:index` and `inference:index`.
- Review inference traces with `rlm.distill` to propose a reusable decomposition policy, then apply accepted definitions through the ordinary self-mutation workflow.
- Preserve intentional mutations to foreign definitions during private replay. Provider, conversation, workspace-state, MCP, and session subsystems now use their dedicated libraries.

## Platforms and recovery

- Add Windows x86-64 launchers, bootstrap and packaging, Unicode-path handling, and native PowerShell command execution through the AppContainer helper. Detached sessions, fork-based image operations, and filesystem sockets are unavailable on Windows.
- Start a rescue session with `autolith resume --pristine`. This boots tracked source without private mutation replay or executable user initialization. Automatic recovery also uses pristine source.
- Accept custom SBCL versions such as `2.6.8.termux` through one shared Lisp compatibility check. Bootstrap can proceed without managed implementation sources when no exact source archive is tracked. Fixes [#68](https://github.com/lambda-symbolics/autolith/issues/68).
- Retrieve known pages with `web_extra.gist`, accept spaces in resource identifiers, and use provider models without reasoning support.

Update with `(update)`.
