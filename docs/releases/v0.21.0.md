# Autolith 0.21.0

Autolith 0.21.0 adds native Responses context compaction for Codex subscription
models, preserving private reasoning state across long-running conversations
without giving up a portable handoff when the model family changes.

## Native Responses compaction

- Codex conversations now use the Responses =/responses/compact= endpoint with
  a full durable history and retained reasoning context.
- Each checkpoint keeps the opaque same-family compaction item alongside a
  concise readable handoff for a later Grok or other-family session.
- An unavailable native endpoint falls back to the existing summary compaction
  path. Endpoint replies may contain incidental output, but Autolith accepts
  only one validated opaque checkpoint.

## Conversation presentation

- Turn timestamps can be enabled as dim optional metadata, keeping the normal
  transcript uncluttered while making long-running sessions easier to audit.

## Maintenance

- Grouped the source tree by runtime component, keeping the live system easier
  to navigate without changing its public behavior.
