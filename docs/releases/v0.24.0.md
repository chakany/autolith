# Autolith 0.24.0

Autolith 0.24.0 adds reliable provider-backed web search and Fireworks API-key model access while hardening startup and authentication recovery.

- Add `web.run`, backed by the authenticated Codex standalone search endpoint, with cached and live access modes and cited results.
- Match Codex search request and response behavior, and retry transient SBCL DNS failures.
- Add the Fireworks Responses provider, model-family routing, endpoint selection, reasoning configuration, tool calls, and API-key login.
- Prefer current `FIREWORKS_API_KEY` values over saved credentials, hide interactive key entry, and report rejected static keys without invalid OAuth refresh attempts.
- Stream legacy conversation migration one form at a time and skip large files without legacy references, preventing startup stack exhaustion.
- Return exact Boolean conversation reservation results, preventing collision-time type errors.
