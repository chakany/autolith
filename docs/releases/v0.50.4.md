# Autolith 0.50.4

## Models

- Add `gpt-6-sol` and `gpt-6-luna` through ChatGPT subscription access, including their reasoning levels and Fast mode.

## Skills

- Fix instruction injection after `skill.load`. Request-context contributors now receive filtered raw tool namespaces; provider wire encoding happens separately. Selected instructions are included in subsequent requests during the logical turn.
- Create and replace global Markdown skills with `skill.edit`. Validate the complete definition before atomic replacement, preserving the existing skill if validation or publication fails.

## Memory and conversation history

- Filter memory collections by query and result limit while keeping revision-gated writes valid against the complete collection state.
- Search durable conversation messages with `session.search`, then inspect neighboring messages with `session.read` using the returned conversation ID and offset.
