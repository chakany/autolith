# Autolith 0.26.0

Autolith 0.26.0 hardens provider boundaries, clarifies tool activity, and improves local multi-session control.

- Normalize provider transport and model-discovery failures into safe typed conditions without exposing credentials.
- Bound streaming SSE lines and events, reject malformed discriminators and incomplete tool calls, and assemble streamed tool arguments in linear time.
- Organize Responses and Chat Completions wire behavior behind shared CLOS classes and generic operations, reducing concrete providers to their real differences.
- Render structured tool arguments and results as readable nested fields, including explicit resource edit operations and ranges.
- Give localgroup sessions timestamp-bearing idsmall identifiers, modern width-aware boxes and colors, plain redirected output, start times, legacy ID compatibility, and constant-time output queues.
- Prefer direct parent work over pointless single-child delegation and remove tests that pinned incidental prompt wording.
- Overlap independent recovery probes with the test suite to shorten repository verification.
- Reject workspace files that change while being observed and preserve revision-gated editing semantics.
