# Autolith 0.18.0

Autolith 0.18.0 expands native development and workspace configuration while
improving MCP interoperability and terminal presentation.

## Native macOS and workspace configuration

- Added native macOS arm64 source-checkout support, including platform-specific
  terminal sizing, fff library loading, checkpoint support, and the Seatbelt
  command sandbox backend.
- Added trusted directory-scoped MCP configuration and executable initialization
  files with workspace inheritance and transactional extension registration.
- Corrected workspace switching so target initialization observes the target
  process directory and pathname defaults.

## MCP and terminal improvements

- Improved FastMCP interoperability and preserved JSON false/null schema values.
- Accepted repeated identical HTTP session headers where the protocol permits
  them.
- Aligned child-agent role columns with their descriptions and status details.
