# Autolith 0.45.0

Autolith 0.45.0 adds ChatGPT browser authentication and strengthens long-running agent, worker, and tool execution.

- Adds ChatGPT browser OAuth with PKCE, bounded local callbacks, refreshable credentials, and a device-authentication fallback.
- Keeps ordinary and recovery sessions detachable, restores durable task results after resume, and formalizes Lisp worker and MCP transport configuration protocols.
- Bounds provider request loops and MCP result text, reserves a final recursive-inference answer call, and compacts conversations from native checkpoints.
- Handles the newest queued steer first after Escape and routes authentication streams through the active terminal.
- Tightens command permission classification, explicit false tool arguments, worker request decoding, and OAuth error redaction.
