# Autolith 0.21.3

Autolith 0.21.3 makes slash-command feedback easier to distinguish and fixes
noninteractive first-run startup on macOS arm64.

## Command feedback

- Slash-command output now shows the exact originating command on a colored line
  above the result.
- A visible result marker separates command confirmations from user and agent
  conversation text.
- The same presentation covers unknown commands, expected command errors,
  active-turn commands, and commands scheduled until the current response ends.

## macOS package startup

- Noninteractive startup now falls back before inspecting terminal input mode,
  avoiding a Darwin failure when standard input is redirected.
- Nix smoke failures now publish bounded diagnostics as workflow annotations.
