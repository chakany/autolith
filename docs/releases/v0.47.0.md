# Autolith 0.47.0

Autolith 0.47.0 expands provider support and hardens concurrent agent operation.

- Adds `gpt-6-astra` to the ChatGPT Codex provider with a 272,000-token context window and its current reasoning effort set.
- Serializes agenda, memory, and papercut transactions across processes so concurrent agents cannot overwrite each other's updates.
- Preserves the distinction between JSON `false` and `null` across decoding and re-encoding while keeping decoded booleans compatible with existing callers.
- Updates the process sandbox to terminate complete process groups on Linux, macOS, and supported BSD systems.
- Strengthens provider streaming, retries, bounded response handling, authentication recovery, and terminal outcome classification.
- Improves task, Lisp worker, conversation, localgroup, resource, MCP, and terminal lifecycle reliability under interruption and concurrency.
- Structures skill catalog sections for clearer request-local discovery and loading.

The `gpt-6-astra` metadata was checked against [openai/codex commit `531f3836a1e38ea61eaaba3dccda6711eb6c0dca`](https://github.com/openai/codex/tree/531f3836a1e38ea61eaaba3dccda6711eb6c0dca).
