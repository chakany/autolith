# Autolith 0.17.1

Autolith 0.17.1 makes unprompted self-modification structurally possible
and stops models, notably grok-4.5, from routing ad hoc computation
through shell interpreter one-liners instead of the live Lisp workers.

## Shell interpreter discipline

- Extended the system prompt's Python rule to inline one-liners: never
  run python3 -c or another interpreter one-liner through shell.run for
  computation or text transformation that lisp.eval performs directly in
  a disposable worker.
- Added a built-in request-local context contributor that detects a
  shell.run interpreter one-liner in the current logical turn and
  injects a mandatory corrective note steering comparable work back to
  lisp.eval. The note clears with the logical turn and never enters
  durable conversation history.

## Periodic self-modification review

- Added a built-in session contributor that periodically reminds the
  model to scan the recent conversation for Autolith-side friction worth
  a small self-modification, phrased as a review and never a mutation
  quota.
- Gated the reminder on both a user-turn period and accumulated working
  time, so rapid exchanges and short dedicated sessions never see it,
  and suppressed it entirely for compaction requests and immutable
  sessions. All thresholds are reloadable policy parameters.

## Working time on the status row

- Accumulated each conversation's working time from durable record
  timestamps, excluding the idle gaps while the user reads and types,
  with exact reconstruction on resume.
- Right-aligned the total worked time on the live status row beside the
  running activity clock, dropping it first on narrow terminals.
