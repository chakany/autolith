# Autolith 0.22.1

Autolith 0.22.1 is a focused provider-diagnostics hotfix.

- Preserve the structured `response.incomplete` reason in durable provider
  failure metadata after bounded retries are exhausted.
- Keep the stable `response_incomplete` classification and retryable condition
  semantics separate from reasons such as `max_output_tokens`.
- Add persistence and stream-classification regressions for incomplete response
  reasons.

This release integrates Jack Chakany's follow-up contribution while retaining
Autolith's bounded retry behavior.
