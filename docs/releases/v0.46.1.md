# Autolith 0.46.1

Autolith 0.46.1 repairs malformed tool-call histories and strengthens unattended recovery.

- Validates provider function-call arguments as exactly one JSON object before persistence, substitutes `{}` for malformed calls, and returns correlated failed tool outputs so the turn can continue.
- Repairs malformed tool arguments from histories written through v0.46.0 in memory during resume while leaving append-only records unchanged.
- Keeps retrying transient provider transport failures with bounded backoff while preserving bounded authentication recovery and definitive failure handling.
- Reaps pristine abandoned localgroup sessions after terminal ownership disappears.
- Disables reader evaluation while parsing `self.redefine` forms.
