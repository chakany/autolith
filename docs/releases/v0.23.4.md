# Autolith 0.23.4

Autolith 0.23.4 prevents stalled release-builder checks from blocking every later release.

- Give each release-builder container a unique managed name.
- Bound complete container build and check runtime to 30 minutes by default.
- Allow operators to override the deadline with
  `AUTOLITH_RELEASE_CONTAINER_TIMEOUT_SECONDS`.
- Print bounded container process and log diagnostics after failure or timeout.
- Force-remove the complete managed container before the polling loop retries.
- Add regression coverage for timeout command construction, structured failure,
  managed naming, and forced cleanup.
