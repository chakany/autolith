# Autolith 0.34.0

Autolith 0.34.0 repairs private live-image commits on clean source installations and includes the recursive language model runtime introduced since 0.33.8.

- `self.commit` now loads locked project dependencies in every fresh lease-test child before loading Autolith.
- Clean child failures include their captured diagnostics instead of a generic lease-owner assertion.
- Recursive inference provides bounded frames, parallel maps, and root completions over external context objects.
- Auto permission mode can classify commands through bounded inference while preserving explicit admission limits.
