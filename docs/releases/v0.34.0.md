# Autolith 0.34.0

Autolith 0.34.0 is the RLM release. More than fifty commits add a recursive language model runtime that lets Autolith reason over material too large for a single model request while keeping context, recursion, and cost explicitly bounded.

- `rlm.infer` runs isolated inference frames over selected read-only views, with optional structured result contracts and confined read capabilities.
- `rlm.map` fans independent analyses out concurrently under one shared call and token budget.
- `rlm.complete` keeps oversized context outside the root prompt while a dedicated Lisp environment searches, slices, delegates, aggregates, and records the final answer.
- Content-addressed context objects and windowed trace logs preserve bounded inputs, outputs, budgets, and provenance across compaction.
- Atomic call admission and output-token tranches keep recursive trees inside their declared limits, including concurrent endpoint work.
- Auto permission mode can use a bounded inference frame to classify shell commands instead of relying on a hard-coded heuristic.
- `self.commit` now works on clean source installations by loading locked project dependencies in fresh lease-test children, with clean-registry coverage and captured diagnostics.
