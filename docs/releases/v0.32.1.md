# Autolith 0.32.1

Autolith 0.32.1 fixes provider search, long-lived workspace revision retention, MCP tool compatibility, and semantic prompt rendering.

- Dispatch standalone `web.run` request headers through the active provider so Grok uses its own authentication, session, and model headers.
- Lazily split workspace resource snapshots and bound their decoded-string retention to 16 MiB per conversation, preventing hundreds of megabytes of old-generation retention in long-lived multi-agent sessions.
- Fit stable MCP namespaces and tool names into reversible 64-character Chat Completions wire names while retaining 64-bit collision identities and exact raw-name routing.
- Retract the live region before the OSC 133 prompt-start marker and emit `A;redraw=0`, preventing stale status remnants and terminal-managed prompt erasure during resize.
