# Autolith 0.20.3

Autolith 0.20.3 closes durability and isolation regressions found during the
post-0.17.2 audit, and makes release discovery tolerant of annotated tags.

## Pending input durability

- Shutdown no longer lets a delayed queue publisher erase the final pending
  input snapshot.
- Pending steering and follow-up snapshots are isolated by conversation, with
  automatic migration of the legacy process-global snapshot.

## Rate-limit recovery

- Streamed provider `rate_limit_exceeded` errors now enter the normal retry and
  follow-up deferral path.
- Inputs deferred after a rate limit remain scheduled when a later attempt is
  rate-limited again.

## Workspace plans

- Durable plans are isolated by workspace, so updating or clearing one
  workspace cannot overwrite another workspace's plan.
- Existing process-global plan state migrates when its owning workspace next
  loads it.

## Release service

- Remote annotated release tags are peeled to their commit identities before
  validation and build selection.
