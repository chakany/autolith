# Autolith 0.23.1

Autolith 0.23.1 fixes Nix image installation and upgrade reliability.

- Validate active and recovery image construction inside Nix while publishing
  only a deterministic marker instead of nondeterministic SBCL core files.
- Build machine-local active and recovery images on first launch without
  requiring user-installed Quicklisp, a compiler, or a source checkout.
- Isolate complete image pairs by exact package identity, publish them atomically
  under a cross-platform lock, and rebuild corrupt cached images automatically.
- Preserve private mutation history across package upgrades and retain prior
  package image directories for already-running Autolith processes.
- Restore exact operating-system-version compatibility for active images.
- Add Linux and macOS Nix checks for deterministic validation, concurrent first
  launch, corruption recovery, cache reuse, and source-distinct package upgrades.
