# Autolith 0.31.1

Autolith 0.31.1 hardens release-host upgrades when the tracked minimum SBCL version changes.

- Clear inherited `AUTOLITH_SBCL` and `AUTOLITH_SBCL_SOURCE_ROOT` bindings before candidate bootstrap, check, and probe processes.
- Let each candidate select or install a runtime that satisfies its own tracked minimum instead of remaining pinned to the active deployment's older runtime.
