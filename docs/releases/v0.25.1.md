# Autolith 0.25.1

Autolith 0.25.1 delegates reusable runtime mechanics to focused Common Lisp libraries while preserving Autolith's product-specific safety and recovery guarantees.

- Delegate compact conversation identifiers to `idsmall`, retaining transactional legacy migration and aliases.
- Read Skills, native MCP configuration, and child-agent role files through bounded `sexp-config` grammars.
- Store and probe retained images through `sbcl-generations`, with exact provenance, credential clearing, and inherited-worker detachment.
- Run child agents on a reusable `cl-jobpond` worker pool with atomic hurry-up admission, cancellation, deadlines, retention, and serialized policy updates.
- Use `cl-exec-sandbox` for macOS Seatbelt policy translation while preserving bounded output, caller-selected deadlines, and invalid UTF-8 replacement.
- Package every extracted dependency for locked Quicklisp and Linux/macOS Nix builds.
